RichMediaColorScheme

enum RichMediaColorScheme

Color scheme the SDK reports to Rich Media content. It drives the prefers-color-scheme CSS media query inside the Rich Media WebView.

Configured via setRichMediaColorScheme or the com.pushwoosh.rich_media_color_scheme meta-data tag in AndroidManifest.xml.
