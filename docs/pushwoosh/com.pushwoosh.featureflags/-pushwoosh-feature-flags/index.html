PushwooshFeatureFlags

class PushwooshFeatureFlags

Feature flags evaluated by Pushwoosh for this device and user.

Obtain it with Pushwoosh.getInstance().getFeatureFlags(); there is one instance per process, so it is safe to keep a reference. get reads the local cache only and never blocks on the network; the SDK refreshes the cache on app start, on return from background after 30 minutes, hourly while in foreground, after the first registration and after setUserId. Do not store personal data in flag properties.
