PushwooshInline

object PushwooshInline

Inline slots: places in the app's own screens that show banners chosen by the server.

Put a PushwooshInlineView with a slot id on screen and the SDK requests, draws and reports its banner by itself. Apps that draw banners themselves read them with getBanner, report them with trackShown, trackClick and dismiss, and follow changes through listener.

Every method may be called from any thread. The work and all callbacks run on the main thread; methods without a result return at once.

requestSlots
Link copied to clipboard
@JvmStatic
fun requestSlots(slotIds: List<String?>?, callback: PushwooshInlineRequestCallback?)

Requests the banners of up to 10 slots now. Empty ids and duplicates are dropped. Manual requests are limited to 5 per session, then one per 3 minutes; the slots keep their banners when a request fails. callback gets null on success, else a PushwooshInlineException. A null list or a null id fails the call with PushwooshInlineException.INVALID_ARGUMENT.
