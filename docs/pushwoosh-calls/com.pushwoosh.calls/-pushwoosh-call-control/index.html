PushwooshCallControl

object PushwooshCallControl

Controls the microphone and the speakerphone of the active VoIP call.

Each method hands the request to the system and reports a successful result once it is handed over. The actual microphone state and audio route are reported to your CallAudioStateListener. If there is no answered call in progress (or the device runs Android below 8.0), the callback receives a PushwooshException with the message No active call.

PushwooshCallControl.mute { result ->
    if (!result.isSuccess) {
        Log.w("App", "Mute failed: ${result.exception?.message}")
    }
}
